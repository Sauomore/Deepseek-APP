Deepseek APP 1.0.7 —— 安装说明
================================

一、安装
---------
1. 把 Deepseek-APP-1.0.7-release.apk 传到手机（微信/QQ 传文件、数据线、网盘均可）。
2. 在手机上点开该文件安装。
   首次安装时系统会提示「未知来源应用」，需要在弹窗里允许「来自此来源」的安装，
   然后返回继续安装。
3. 桌面出现蓝色「DS」图标、名字为「Deepseek APP」即安装成功。

系统要求：Android 7.0（API 24）及以上。


二、第一次打开
---------------
会看到欢迎页，有两个选择：

  A. 先体验演示模式
     不需要任何账号或 Key，所有功能都能点，回答来自内置示例内容。
     适合先把界面和交互摸清楚。

  B. 填入 API Key
     1) 浏览器打开 https://platform.deepseek.com/api_keys
     2) 注册/登录后点「创建 API Key」，复制形如 sk-xxxxxxxx 的字符串
     3) 粘贴到欢迎页输入框，点「填入 Key 并开始」

请注意：Key 只保存在你手机本地，所有请求直接发往 DeepSeek 官方接口，
不经过任何第三方服务器。使用会产生你自己的 API 费用（很便宜，一条回答通常不到 1 分钱）。


三、常用操作
-------------
· 输入框上方两个开关
    深度思考 —— 让模型先推理再回答（面板可展开看推理过程）
    联网搜索 —— 需要最新信息时打开，回答里会带来源卡片和引用角标

· 顶部模型名（V4.1 Flash）—— 点一下可切换
    deepseek-flash   速度快、支持识图（默认）
    deepseek-v4-pro  推理更强，但不支持图片

· 输入框左边「+」
    相册 / 拍照 / 文件（PDF、Word、PPT、Excel、txt 等）/ 语音输入

· 输入框右边常驻发送按钮（灰色=没内容，蓝色=可发送）· 长按输入框开始录音，松手自动转文字

· 左上角三横线 —— 会话列表，可搜索、重命名、置顶、删除

· 右上角齿轮 —— 设置
    填/换 API Key、演示模式开关、内容安全审核、模型与思考强度、
    主题（跟随系统/浅色/深色）、字号、震动反馈、清空对话（发送只用右侧按钮，回车换行）


四、常见问题
-------------
Q: 提示「API Key 无效或已失效（401）」
A: Key 复制不完整，或已被删除。去 platform.deepseek.com 重新创建一个。

Q: 提示「账户余额不足（402）」
A: 你的 DeepSeek 账户余额用完了，去平台充值即可。

Q: 图片发不出去 / 模型说看不到图
A: 当前模型是 deepseek-v4-pro，它不支持识图。切回 deepseek-flash。

Q: 上传 txt / xlsx 失败
A: 这类文件走的是「无需解析」通道，单文件上限 32MB；PDF/Word/PPT 上限 100MB。

Q: 语音没有反应
A: 语音是「长按输入框」触发的：按住输入框约半秒会弹出录音界面，松手自动转成文字。
   第一次使用时系统会问是否允许录音，选「允许」。
   如果误点了拒绝，到 手机设置 → 应用 → Deepseek APP → 权限 里打开麦克风。
   也可以点输入框左边的「+」，在「语音」里手动开始录音。

Q: 连接失败 / 一直转圈
A: 检查手机网络；如果用了代理/VPN，确认能访问 api.deepseek.com。

Q: 想换回演示模式
A: 设置 → 接口与账号 → 打开「演示模式」。

Q: 应用占多大空间？会收集我的数据吗？
A: 安装包约 5.9MB。应用不含任何统计、追踪、广告 SDK，
   对话只保存在手机本地，也只发送给 DeepSeek 官方接口。


五、卸载与数据
---------------
卸载应用会一并删除本机保存的所有对话记录和 API Key，请自行备份重要内容。


六、关于
---------
这是一个非官方第三方客户端，仅用于个人学习与自用，与 DeepSeek 官方无关。
所有对话内容会发送给 DeepSeek 官方接口，请遵守其服务条款。
